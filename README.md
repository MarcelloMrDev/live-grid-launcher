# 🎥 Live Grid Launcher

Sistema para **captura de transmissões ao vivo, DVR e geração de grids**, desenvolvido para facilitar o gerenciamento e processamento de lives através de uma interface simples.

> 🚧 Projeto atualmente em desenvolvimento.

## 🚀 Funcionalidades

- 📡 Captura de transmissões ao vivo
- ▶️ Reprodução da live
- ⏪ Sistema de DVR
- 🎞️ Controle e processamento da transmissão
- 🖼️ Geração de grids
- 🔄 Atualização da transmissão
- 🖥️ Interface web para controle
- ⚙️ Backend desenvolvido em Python
- 🌐 Execução local através do navegador
- 📦 Inicialização simplificada

## 🛠️ Tecnologias

O projeto utiliza principalmente:

- Python
- HTML
- CSS
- JavaScript

## 📂 Estrutura

```text
live-grid-launcher/
│
├── run.py
├── live_engine.py
├── index.html
└── outros arquivos do projeto
```

### `run.py`

Responsável pela inicialização da aplicação.

### `live_engine.py`

Responsável pela lógica principal de processamento e gerenciamento das transmissões.

### `index.html`

Interface utilizada para controlar e visualizar o sistema.

## ▶️ Como executar

### 1. Verifique se o Python está instalado

```bash
python --version
```

### 2. Clone o projeto

```bash
git clone https://github.com/MarcelloMrDev/live-grid-launcher.git
```

### 3. Entre na pasta

```bash
cd live-grid-launcher
```

### 4. Execute

```bash
python run.py
```

## 🎯 Objetivo

O **Live Grid Launcher** foi criado para simplificar o processo de captura e gerenciamento de transmissões ao vivo.

A proposta é centralizar diferentes ferramentas relacionadas à transmissão em uma única aplicação, tornando o processo mais rápido e organizado.
